# 阅读

纯静态阅读器。EPUB 与 TXT 都在浏览器里解析，导入后存进 IndexedDB，没有服务端、没有构建步骤。

## 导入

点右上角「导入」，或把文件拖进书架。支持 `.epub` 和 `.txt`，可多选。

书籍只存在当前浏览器里（IndexedDB），换浏览器或清缓存需要重新导入。卡片右上角的「移除」可以把书从本地删掉。

## 阅读

- 目录：按卷 / 章分组，可折叠、搜索。
- 翻章：正文底部按钮、右上角箭头，或键盘 `←` / `→`。
- 阅读模式：滚动 / 点击翻页。点击翻页模式在手机端会尝试进入全屏。
- 手机翻页：点击阅读区左侧 / 右侧翻页，到章末自动切换上一章 / 下一章；点击中间可唤回顶栏。
- 注释：鼠标移到上标、键盘聚焦或点按上标，会在旁边浮层显示注释。
- 进度与书签：存在浏览器 localStorage，重开回到上次位置。
- 格式：深色 / 浅色 / 跟随系统（与工作台首页共用偏好）；阅读纸色可选纸（纯白）/ 米，深色模式自动使用夜色阅读页；宋体 / 黑体 / 楷体 / 霞鹜文楷，细体 / 常规 / 粗体三档字重，字号、行距、版心宽度、缩进可调。
- 字体：霞鹜文楷使用 jsDelivr 网络字体，离线时自动回退到系统楷体。
- 返回：书架顶部与阅读页右上角都有「工作台」入口，可直接回到首页；页脚也保留入口。
- 快捷键：`T` 目录，`B` 书签，`S` 格式，`Esc` 返回书架；书架页 `/` 定位搜索。

## 文件

```text
reader/index.html 页面
reader/library.js EPUB / TXT 解析
reader/store.js   IndexedDB 书库
reader/app.js     交互
reader/styles.css 样式
```

## 说明

- EPUB 仅支持未加密（无 DRM）的书籍。
- 依赖 `DecompressionStream`，需要 Chrome 103+ / Firefox 113+ / Safari 16.4+。
- 需通过 http(s) 访问（本地起个静态服务器或直接看 GitHub Pages）；`file://` 下浏览器会限制 IndexedDB。
