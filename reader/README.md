# 灯下 · 本地阅读

一个零依赖的本地小说阅读网站。服务端直接读取 `book/` 目录中的 `.epub` 和 `.txt`，浏览器里完成书架、分章阅读、章节跳转、书签与排版设置。

## 启动

双击 `html/start-reader.cmd`，或在 `html/` 目录执行：

```powershell
node server.mjs
```

然后打开 <http://127.0.0.1:8787/reader/>。端口被占用时可以指定其他端口：

```powershell
node server.mjs --port 8788
# 或双击 html\start-reader.cmd 8788
```

需要 Node.js 18 或更高版本。关闭运行服务的终端窗口即可停止服务。

## 放书

把 `.epub` 或 `.txt` 放进 `html/book/`，刷新书架即可。文件名会作为 TXT 的书名；EPUB 会读取包内元数据和封面。

- EPUB：读取 `container.xml`、OPF 目录顺序和 NCX/EPUB3 导航，按脊（spine）分章。
- TXT：支持 UTF-8、UTF-16 和 GB18030 编码切换；自动识别 `第X章 / 第X节 / 第X回 / 第X卷` 一类的章节标题，没有标题时按长度自动分段。
- 全部解析在本地完成，没有外部字体、CDN 或网络请求。

## 阅读

- 目录支持搜索，点击章节即可跳转；正文底部还可以输入章节序号直接跳转。
- 上一章 / 下一章：正文底部按钮、右上角箭头，或键盘 `←` / `→`。
- 阅读进度、格式设置会保存在浏览器 localStorage 中；重新打开会回到上次的章节和位置。
- 书签：右侧「书签」按钮打开面板，可收藏 / 移除当前章节，并从书签回到原阅读位置。
- 格式：纸 / 茶 / 夜三种主题，宋体 / 黑体 / 楷体，字号、行距、版心宽度、首行缩进都可调。
- 快捷键：`T` 目录，`B` 书签，`S` 格式，`Esc` 返回书架；书架页 `/` 定位搜索框。

### Windows 字体

Windows 浏览器对未微调的中文衬线字体（尤其是小字号）渲染偏细。阅读器会自动识别 Windows，并默认用屏幕渲染更清晰的微软雅黑作为正文字体；章节标题仍保留宋体，以保留书卷感。喜欢纯宋体阅读时可以在「格式 → 正文字体」中切回宋体，Windows 下会自动使用更合适的 500 字重。

如果切换后仍觉得文字发虚，优先检查两处：

1. 浏览器缩放是否为 100%；
2. Windows 的显示缩放和 ClearType 是否设置正常（控制面板搜索「调整 ClearType 文本」）。

字体设置会记住你的主动选择，不会被后续启动覆盖。

## 文件结构

```text
html/
├─ book/                 # 放 EPUB / TXT
├─ reader/
│  ├─ index.html
│  ├─ styles.css
│  └─ app.js
├─ server.mjs            # 本地服务与书籍解析
├─ start-reader.cmd      # Windows 一键启动
└─ index.html            # 原有的本地起始页，未改动
```

## 说明

- 网站只监听 `127.0.0.1`，不会暴露到局域网。
- EPUB 仅支持未加密（无 DRM）的书籍；加密文件会被跳过。
- 服务端不写入书库；阅读进度、书签和格式都只存在当前浏览器。
